# Portafolio de Raúl Larrea

Construido con Next.js, React y Tailwind CSS.

## Requisitos

- Node.js 20.9 o posterior
- npm

## Clonar e instalar

```bash
git clone https://github.com/Hardash01/porfolio-deployment.git
cd porfolio-deployment
npm install
```

## Ejecutar en desarrollo

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en el navegador. En PowerShell puedes usar `npm.cmd` en lugar de `npm` si tu entorno lo requiere.

## Preparar y ejecutar producción

```bash
npm run build
npm start
```
